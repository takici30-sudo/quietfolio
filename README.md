# Quietfolio

A responsive personal portfolio starter with warm editorial typography, two project cards, an about section, and a contact link. Pure HTML and CSS, with no dependencies or build step.

## 使用方法 / Getting started

Download or clone this repository and open `index.html` in a browser. No installation is required. You can also publish the repository root with GitHub Pages.

下载源码后直接双击 `index.html` 即可使用，无需安装依赖。

## Customize

- Replace `Your Name`, the sample biography, and `hello@example.com` with your own details.
- Update the two sample project descriptions and repository links.
- Change the colors in the `:root` block near the top of `index.html`.
- Decorative project thumbnails are made entirely with CSS; no image downloads are needed.

## Included

- Responsive layout and anchor navigation.
- Visible keyboard focus and reduced-motion support.
- No JavaScript, trackers, remote fonts, or external assets.

The name, biography, and contact address are demonstration content, not claims about the repository owner. This is a starter template; no automated tests or dependency installation were performed.
